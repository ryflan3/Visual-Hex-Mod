# Visual Hex Satellite

A tileset mod for [Unciv](https://github.com/yairm210/Unciv) that makes the map look like satellite imagery: hill-shaded terrain, mountains that rise above their tiles, and soft transitions where terrains meet.

*Both previews are made by `tools/preview_map.py`, which lays the images out using the same rules as the game. They aren't screenshots from Unciv.*

## Install

1. In Unciv, open **Mods** and choose **Download mod from URL**. Paste `https://github.com/ryflan3/Visual-Hex-Mod`.
2. On the Mods screen, select the mod in the **Installed** column and tick **Permanent audiovisual mod**.
3. Open **Options → Display** and set **Tileset** to **Visual Hex Satellite**.

Unciv downloads the repository's default branch.

## What's included

| Group | Images | Notes |
|---|---|---|
| Base terrain | 23 | Grassland, Plains, Desert, Tundra (3 versions each), Snow, Coast (2 each), Ocean (3), Lakes, Mountain (3) |
| Terrain features | 12 | Hill and Forest and Jungle (2 versions each), Marsh, Flood plains, Oasis, Ice, Atoll, Fallout |
| Rivers | 3 | `River-Bottom`, `River-BottomLeft`, `River-BottomRight` |
| Edge transitions | 135 | See below |
| Map overlays | 22 | Selection hex, highlight, crosshair, fog clouds, unexplored clouds, 8 border pieces, 7 movement arrows, road, railroad |

All 195 images pack onto **one 2048×2048 texture sheet**. That's about 21 MB of graphics memory including mipmaps, so it should run on phones as well as desktop.

Improvements, resources, natural wonders and city centers aren't drawn by this tileset. They come from the built-in **HexaRealm** tileset, so they keep their pixel-art style.

### Edge transitions

Edge images are drawn on a tile when a neighbour on one side matches. File names follow Unciv's `Name-Origin-Destination-Direction` pattern.

| Set | Count | Drawn on | When the neighbour is |
|---|---|---|---|
| `Blend` | 60 | the lower-priority land terrain | another land terrain. All 10 pairs of Grassland, Plains, Desert, Tundra and Snow. The higher one spreads into the lower: Snow > Grassland > Plains > Tundra > Desert |
| `Shore` | 30 | each of those 5 land terrains | water. The beach is sand, gravel or ice depending on the terrain |
| `Scree` | 30 | each of those 5 land terrains | a mountain |
| `Foam` | 6 | any water tile | land |
| `Shelf` | 6 | ocean | coast |
| `Cliff` | 3 | mountain | water to the south |

## How the images are made

Every image is generated by `tools/render_tiles.py` (Python with NumPy and Pillow). There's no hand-painted art, so you can change the look by editing the script and rebuilding.

* **Image shape.** Unciv draws each tile image at the hex's width, keeps its aspect ratio and anchors it at the bottom. The bottom 224×194 pixels of a terrain image are the hex. Anything taller, like mountains and tree crowns, rises above the tile. Tiles lower on screen are drawn over the ones above. Edge images are 112×97, exactly the same aspect ratio, so they line up with the tiles to the pixel.
* **Seamless textures.** Every base texture repeats on the hex grid, so two neighbouring tiles of the same terrain continue each other. Alternate versions (`Grassland2`, `Grassland3`) only differ in the middle of the tile, so they join seamlessly too.
* **Blends.** A blend image paints the neighbour's own texture, which continues across the shared edge, and fades it out toward the tile centre.
* **Overlays.** The game can only fall back one tileset deep, and HexaRealm gets its overlays from FantasyHex. So this tileset includes its own overlays (borders, arrows, roads, the selection hex). They use the same geometry as the base game's pieces.

## Rebuilding

```bash
tools/build.sh             # render all images, pack the atlas, refresh the previews
tools/build.sh Mountain    # only re-render images whose path contains "Mountain", then pack
```

You need Python 3 with `numpy` and `pillow`, plus Java 11 or newer. The script downloads the libGDX 1.14.2 texture packer (the version Unciv uses) into `.gdx/`. `tools/PackAtlas.java` packs with the same settings as Unciv's desktop packer: 2048 px pages, 8 px padding and mipmaps.

Android can't pack images on the device, so the packed `game.atlas`, `game.png` and `Atlases.json` are committed. The **Pack texture atlas** GitHub workflow repacks and commits them whenever files under `Images/` change.

## Known limitations

* **In-game testing.** This version was checked with the preview tool, not yet in Unciv itself.
* **Edge order.** Unciv draws edge images after terrain features, so a beach or blend along a forest tile's edge paints over the trees right at that edge.
* **Mountain cliffs.** Cliffs only appear on the south sides of mountains. On the north sides the mountain rises over the edge, and an edge image would paint across it.
* **Fallback art.** HexaRealm's improvements and resources are pixel art, so they look flatter than the terrain under them.

To list the mod in Unciv's in-game mod browser, add the `unciv-mod` topic to the GitHub repository.
